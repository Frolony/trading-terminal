# coordination-kernel (Solidity, v0.4.5)

Contracts, build and a local-EVM test harness. Nothing here has run on a live network.

## Run it

    npm ci
    npm test

`npm test` compiles every contract and runs the core suite (`test/amalgam.js` plus `test/part2.js`) and then the Arc transfer suite (`test/transfer.js`). It exits non-zero if any check fails. Individual runs: `npm run test:core`, `npm run test:transfer`, `npm run build`.

* Node 20 or newer (run here on 22.22.0). Dependencies are pinned exactly in `package.json` and `package-lock.json`: ethers 6.13.4, ganache 7.9.2, solc 0.8.28. Use `npm ci`, not `npm install`, so the lock is honoured.
* Expect about 29 minutes in total on a small container (the core suite is slow because every step is a mined transaction on a local ganache chain; the transfer suite is a few minutes of that).
* Ganache prints "Falling back to a NodeJS implementation; performance may be degraded." on start. It is harmless.
* Expected result: `128 passed, 0 failed` for the core suite and `38 passed, 0 failed` for the transfer suite. The reference outputs from the packaging run are in `test/last-run.log` and `test/transfer-run.log`.
* Compiler settings: solc 0.8.28, EVM `paris`, optimizer on with 1 run. `test/build.js` prints each contract's deployed size and flags anything over the EIP-170 limit of 24,576 bytes.

## Layout

* `contracts/` the kernel and its delegatecall modules, plus the Arc transfer vault and constraint (see `ARC.md`).
* `test/` build script, mocks and the suites. `test/art.json` is build output, regenerated by `npm run build`. `kernel.test.js` and `kernel_test.js` are earlier, narrower suites kept for history; they are not part of `npm test`.

## The constructor

`CoordinationKernel` takes a trailing `bool reputationWeighs_`. Pass `false` for the launch profile (influence is the base influence; reputation is recorded but weighs nothing) and `true` for the full reputation-weighted form.
